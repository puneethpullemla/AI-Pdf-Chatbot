# AI PDF Chatbot (RAG)

This project is a Retrieval-Augmented Generation (RAG) chatbot that allows users to upload PDF documents and ask questions about them.

## Features
- Upload PDF files
- Ask questions about documents
- Semantic search using FAISS
- LLM-powered answers

## Tech Stack
- LangChain
- FAISS
- Streamlit
- FLAN-T5
- sentence-transformers

## Run the Project

pip install -r requirements.txt

streamlit run streamlit_app.py
